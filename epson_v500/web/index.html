V500 Scanner

Epson Perfection V500 Photo, driven from the browser over WebUSB. No Epson software involved.

This browser has no WebUSB. Use Chrome or Edge on a computer, and open the page from http://localhost or over https.

2 Firmware

Built into this copy of the page: nothing to set up.

The scanner needs Epson's firmware after every power-on. Get Epson's free Linux driver (650 KB), then drop it on this page or pick it. The page takes the firmware out of it and keeps it in this browser.
